# v1.0.0 — first build (2026-09-14)

Package `dist\gb_tts_1.0.0_win64.ts3_plugin` (3.0 MB; DLL 3.9 MB, deps Qt 5.15.2 + MSVC runtime only).

## Decisions
- **Out-of-process backend** (Python) instead of in-DLL inference: PyTorch crash/OOM can't kill TS3, CUDA DLLs never load into the client. [[system-overview]]
- **Qwen3-TTS 1.7B Base + voice cloning** as the daily path; VoiceDesign only to create voices; first run designs two native-Italian voices. Rejected Voxtral (CC BY-NC, VRAM), XTTS (licence), Kokoro (Italian prosody), Chatterbox (latency). [[engines-and-models]]
- **Streaming everywhere + no disk cache**: replay re-synthesises; only voice references/prompts are stored.
- Defaults from measurement: chunk 4 (TTFA ≈ 0.3 s, RTF 1.4), whole-sentence prefill (intonation), 200 ms start buffer.
- **Soundboard DSP + editor compiled in place**, same trick as Soundboard LIVE; FFmpeg not linked (IR-file loading stubbed).
- Talk state = Soundboard TalkStateManager port + muted-mic lift. [[ts3-integration]]

## Bugs found while building (with root cause)
1. `CERTIFICATE_VERIFY_FAILED: self-signed certificate` downloading models → Kaspersky HTTPS scanning; certifi doesn't trust its root → truststore.
2. `'MimiConfig' object has no attribute 'rope_theta'` → transformers 5.17 vs qwen-tts-hf 0.1.1.post1 → pin 5.15.1. First load attempt hid it behind an online retry: `QwenEngine.ensure` now only goes online for a missing snapshot.
3. `3°` read "tre" → `°` is Unicode `So`, stripped as emoji → whitelist symbols.
4. Build reported "DLL not produced" instead of failing → batch `|| exit /b %errorlevel%` expands to 0 → `if errorlevel 1`.
5. `SPEAKER_FRONT_LEFT` undeclared → `common.h` missing in TtsAudio.cpp.
6. Stop click on block boundary; selftest stack overflow — see [[testing]].
